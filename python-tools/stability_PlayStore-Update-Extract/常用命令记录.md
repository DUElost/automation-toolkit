# 常用命令记录

## 1. 环境安装与核对

执行系统 Python 环境安装与核对脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_playstore_env_global.ps1
```

单独核对 `playstoreapi` 版本与依赖：

```powershell
python -m pip show playstoreapi
python -m pip freeze | findstr /i "playstoreapi requests urllib3 protobuf"
```

单独核对匿名认证：

```powershell
python -c "from playstoreapi.googleplay import GooglePlayAPI; api=GooglePlayAPI('en_US','America/New_York'); api.ssl_verify=True; api.login(anonymous=True); print('OK', api.gsfId)"
```

## 2. 设备画像采集与查看

采集当前设备画像并保存到本地：

```powershell
python .\playstore_downloader.py --collect-device-profile x6852_sample --device 11914404BG102162
```

列出本地已保存的设备画像：

```powershell
python .\playstore_downloader.py --list-device-profiles
```

## 3. Google Play APK 下载

按指定设备画像下载包名清单：

```powershell
python .\playstore_downloader.py --from-file .\top50_applist\applist.txt --device-profile x6852_sample
```

按指定设备画像做最小验证，不实际下载：

```powershell
python .\playstore_downloader.py com.android.chrome --device-profile x6852_sample --dry-run
```

直接读取当前连接设备的实时画像下载：

```powershell
python .\playstore_downloader.py --from-file .\top50_applist\applist.txt --device 11914404BG102162
```

回退到内置默认画像下载：

```powershell
python .\playstore_downloader.py --from-file .\top50_applist\applist.txt --no-device-profile
```

使用 Google 账号模式下载：

```powershell
python .\playstore_downloader.py --from-file .\top50_applist\applist.txt --device-profile x6852_sample --email your_account@gmail.com
```

## 4. 批量安装已下载 APK

执行一键批量安装：

```powershell
powershell -ExecutionPolicy Bypass -File .\install_all_apks.ps1
```

指定设备序列号：

```powershell
powershell -ExecutionPolicy Bypass -File .\install_all_apks.ps1 -Serial 11914404BG102162
```

指定 APK 根目录：

```powershell
powershell -ExecutionPolicy Bypass -File .\install_all_apks.ps1 -Root ".\downloaded_apks_Infinix X6852_Android16"
```

允许降级安装：

```powershell
powershell -ExecutionPolicy Bypass -File .\install_all_apks.ps1 -AllowDowngrade
```

## 5. 原始提取主流程命令

检查 Play Store 待更新应用：

```powershell
python .\playstore_update_extract.py --device 11914404BG102162 check
```

检查并保存待更新包名列表：

```powershell
python .\playstore_update_extract.py --device 11914404BG102162 check --save pkgs.txt
```

按包名直接提取当前设备上的 APK：

```powershell
python .\playstore_update_extract.py --device 11914404BG102162 pull --from-file pkgs.txt
```

创建快照：

```powershell
python .\playstore_update_extract.py --device 11914404BG102162 snapshot --label before_update
```

执行完整主流程：

```powershell
python .\playstore_update_extract.py --device 11914404BG102162 full-flow
```

## 6. 常见辅助命令

查看 ADB 设备：

```powershell
adb devices
```

查看当前目录下已保存的设备画像文件：

```powershell
Get-ChildItem .\device_profiles
```

查看下载输出目录：

```powershell
Get-ChildItem .\downloaded_apks_Infinix*
```

查看某个应用目录下的 APK 文件：

```powershell
Get-ChildItem ".\downloaded_apks_Infinix X6852_Android16\com_opera_browser"
```

## 7. 当前默认路径说明

- 设备画像目录：`.\device_profiles`
- 下载输出目录示例：`.\downloaded_apks_Infinix X6852_Android16`
- 批量安装脚本：`.\install_all_apks.ps1`
- 环境安装脚本：`.\setup_playstore_env_global.ps1`
